# Contributing

Thanks for sharing a process. Everything you need is in the README:

- [Submit a process](README.md#submit-a-process): the folder, `PROCESS.md`, `marketplace.json`, the local check and the pull request.
- [How submissions are evaluated](README.md#how-submissions-are-evaluated): the automatic checks and the review criteria.
- [The format](README.md#the-format): step kinds and every `marketplace.json` field.

A few rules for pull requests:

- One process per pull request, and only its folder. Don't edit the catalog in the README; maintainers regenerate it after merging with `node .github/validate.mjs . --readme`.
- Keep processes general: roles, not names, and no real data, credentials or internal links.
- Report anything unsafe in a listed process as an [issue](https://github.com/agentprocess/marketplace/issues/new), not a pull request, so we can act on it first.
