# Agent Process marketplace

Ready-to-adapt processes for businesses, teams and everyday life, in the open [Agent Process](https://github.com/agentprocess/agentprocess) format. Browse them at [agentprocess.io/marketplace](https://agentprocess.io/marketplace/).

Each folder is one process:

- `PROCESS.md`: the workflow your AI agents follow, which steps people do or approve, and notes for adopting it.
- `marketplace.json`: the title, category, audience and search terms the marketplace shows.

## Use a process

Download a `PROCESS.md` from the marketplace or this repository, adapt the roles, tools and rules to your team, then rehearse it before live use. Any agent or server that supports Agent Process can run it.

These are templates. They don't describe any real organization's procedures, and checking that a file is well formed doesn't make it right for your business. Review the policies, people and access it assumes.
